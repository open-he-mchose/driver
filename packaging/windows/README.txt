mchose-gui for Windows (x64)

Run mchose-gui.exe. No installation or driver is needed: the keyboard's configuration interface is a
standard HID device.

- Close the official web driver (browser) while using mchose-gui; only one program may talk to the keyboard.
- Before changing anything, make a backup (Device tab -> Backup).
- Lighting effects (Effects tab) use live colours only and do not write to the keyboard's flash.

Supported and tested: MCHOSE Jet75-II, firmware V116.
Documentation: https://open-he-mchose.github.io/
